  MACD+KD 共振策略 — 五大衍生策略設計理念
============================================================================================

  原始 MACD+KD 優勢: 三重確認 (趨勢EMA + 動能MACD + 擺盪KD) → 75.8% 勝率
  但仍有改良空間，以下針對不同面向各設計一個衍生策略：

  ┌─────┬─────────────────────┬──────────────────────────────────────────────────┐
  │ ID  │ 策略名稱            │ 改良方向                                         │
  ├─────┼─────────────────────┼──────────────────────────────────────────────────┤
  │  A  │ ATR 動態追蹤停損    │ 固定停損→ATR倍數動態停損+追蹤停利讓利潤奔跑      │
  │  B  │ 成交量確認          │ 進場需放量確認+量價背離提前出場                   │
  │  C  │ RSI 動能過濾        │ RSI 避免超買追多/超賣追空+交叉窗口放寬            │
  │  D  │ 自適應波動率        │ 高波動→寬SL/TP, 低波動→窄SL/TP或不交易           │
  │  E  │ 布林通道位置評估    │ 避免追高/追低+布林帶觸及出場+持倉時間限制         │
  └─────┴─────────────────────┴──────────────────────────────────────────────────┘

  ─── 各策略詳細說明 ─────────────────────────────────────────────────────────

  A. ATR 動態追蹤停損:
     • 停損 = 進場價 ± 2.0×ATR (波動大→空間大, 波動小→精準停損)
     • 浮盈超過 1.5×ATR 後啟動追蹤停損 (trailing distance = 1.0×ATR)
     • 讓獲利單持續奔跑, 而非固定 50 點就了結

  B. 成交量確認:
     • 進場: 成交量 > 20期均量 × 1.2 (有量才是真突破)
     • 出場: 連續 3 根量遞減 + 有浮盈 → 量能衰退提前了結
     • 目的: 過濾量縮時的假訊號

  C. RSI 動能過濾:
     • 做多需 RSI 在 40-65 (不在超買區追高)
     • 做空需 RSI 在 35-60 (不在超賣區追低)
     • MACD 和 KD 交叉允許 3 根 K 線窗口 (不需同 bar 出現)
     • KD 到極端區 (>80/<20) 直接出場

  D. 自適應波動率:
     • ATR 低於 25 percentile → 不開新倉 (避免量縮假訊號)
     • ATR 25-75th → 標準 SL=30/TP=50
     • ATR 高於 75th → 放寬 SL=40/TP=65 (給價格空間)

  E. 布林通道位置評估:
     • 做多時價格不能已在上軌外 (避免追高)
     • 觸及對向布林軌道 + 有浮盈 → 獲利了結
     • 持倉超過 45 根 K 線未達 TP → 市價平倉 (避免盤整耗損)
