
==========================================================================================
  現有策略缺陷分析 — 雙均線交叉策略 (MA5/MA20, 1-min K)
==========================================================================================

  ┌──────────────────────────────────────────────────────────────────────────────┐
  │  缺陷 1: 過度交易 (Over-trading)                                            │
  │  ─────────────────────────────────────────────────                           │
  │  MA5/MA20 在 1 分鐘圖上交叉極為頻繁 → 27 天產生 103 筆交易                   │
  │  平均每天 3.8 筆，手續費+稅金合計 NT$ 30,904 (佔虧損 34%)                    │
  │  → 每次進出場都要付 NT$ 300 成本，小幅盈利被交易成本吃掉                     │
  │                                                                              │
  │  缺陷 2: 追漲殺跌 (Trend Chasing in Range Market)                            │
  │  ─────────────────────────────────────────────────────                       │
  │  均線交叉屬於「趨勢追蹤」策略，但在 1 分鐘尺度上市場大多震盪                 │
  │  → 均線黃金交叉做多 → 價格回落 → 死亡交叉做空 → 價格反彈                     │
  │  → 來回被雙巴 (whipsaw)，勝率僅 27.2%                                       │
  │                                                                              │
  │  缺陷 3: 無出場機制 (No Exit Logic)                                          │
  │  ─────────────────────────────────────────                                   │
  │  唯一出場方式是等反向交叉 → 沒有停損/停利/時間停損                            │
  │  → 小虧可能拖成大虧，浮盈也可能全吐回去                                     │
  │  → Profit Factor 僅 0.60 (每賺 1 元就虧 1.67 元)                             │
  │                                                                              │
  │  缺陷 4: 無過濾條件 (No Entry Filter)                                        │
  │  ───────────────────────────────────────────                                 │
  │  不管波動率高低、成交量大小，一律進場                                        │
  │  → 在低波動/假突破時也會發出交叉訊號 → 勝率進一步下降                        │
  │                                                                              │
  │  缺陷 5: 單一指標依賴 (Single Indicator)                                     │
  │  ──────────────────────────────────────────                                  │
  │  僅靠兩條 SMA 決定進出場，無多指標交叉確認                                   │
  │  → 假訊號率高，沒有「信號可信度」的分級機制                                  │
  └──────────────────────────────────────────────────────────────────────────────┘

==========================================================================================
  改良策略設計
==========================================================================================

  ② RSI 均值回歸 + ATR 波動過濾
     思路: 逆勢操作 — 超賣(RSI<30)買入、超買(RSI>70)賣出
     改善: ATR過濾低波動假訊號 + 冷卻期防過度交易 + 持倉時間上限

  ③ 布林通道壓縮突破
     思路: 等盤整→壓縮→突破，而非隨時進場
     改善: 成交量確認防假突破 + 中軌動態停損 + 每日交易次數限制

  ④ MACD + KD 多指標共振
     思路: 趨勢(MACD) + 動能(KD) + 方向(EMA) 三重確認才進場
     改善: 固定停損30點/停利50點 (R:R=1:1.67) + 時段過濾避開開收盤
